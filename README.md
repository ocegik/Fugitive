# 📚 Fugitive

**Fugitive** is a modern, intuitive **Book Reading app** built with **Jetpack Compose**, **Kotlin**, and **Firebase**.  
It empowers authors to publish their work and readers to explore immersive stories — all within a clean, scalable, and mobile-first interface.

---

## ✨ Features

- 📖 Read chapters in a distraction-free, elegant reader
- 🔍 Explore featured and trending books
- 🧠 Personalized reading history and bookmarks
- ☁️ Real-time updates using Firebase Firestore
- 🧩 Modular UI with Jetpack Compose

---

## 🛠️ Tech Stack

- **Kotlin** — Modern Android development
- **Jetpack Compose** — Declarative UI design
- **Firebase** — Firestore, Auth, Storage
- **MVVM Architecture** — Scalable and testable
- **Material Design 3** — Polished UI/UX
